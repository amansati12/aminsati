# Amin Hasam Sati - Animated Resume Website

Open `index.html` in any browser (internet needed once for Bootstrap, icons and fonts, which load from CDN).

## Structure
- `index.html` - page markup (Bootstrap 5 grid, modals, navbar)
- `css/style.css` - theme, animations, glassmorphism, print styles
- `js/main.js` - resume data, typing effect, scroll reveals, counters, particles, tilt, pop-ups, form
- `images/amin.jpg` - profile photo from the CV

## Edit your data
Skills and experience pop-up details are at the top of `js/main.js`. Contact details are in `index.html`.

## Deploy
Upload the folder to GitHub Pages, Netlify or any web host.
Tip: the "Save as PDF" button uses the browser print dialog with a clean print layout.

## Portfolio
The Portfolio section in `index.html` lists social media management clients, custom software sectors, website projects and digital marketing clients. Edit the corresponding cards to update these lists.


## Visitor counter
`js/visitors.js` shows unique visitors for today, this month, this year and all-time (CounterAPI, free, no signup). Each browser is counted once per period. Change `NAMESPACE` at the top of the file to something unique to your site. Dates use India time.
